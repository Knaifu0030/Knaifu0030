# Visual direction and references

This revision uses an original, character-by-character mountain composition, not image generation, an image underneath ASCII, or a reproduction of a published manga panel. The ASCII source is assets/summit.txt and the generator is build_summit.py.

Inspiration, not copied assets:
- https://github.com/Andrew6rant — monospace composition and character-based imagery.
- https://16colo.rs/ — text-art silhouettes, limited palettes and negative space.
- https://www.avivashishta.com/blog/build-animated-github-profile-readme.html — self-contained SVG animation for README images.
- https://github.com/crafter-station/gh-ascii — character-density and theme-aware rendering approaches.
- https://github.com/mu-ct/awesome-ascii-animation — animation reference collection.
- The Climber — lone climber / mountain theme; no panel copied.

Developer logos originate from Devicon: https://github.com/devicons/devicon (MIT; individual logos remain their owners' trademarks).

Motion is restricted to snow and clouds. Reduced-motion preference selects the static artwork. Icon matrix geometry is fixed at four columns by four rows, with a separate larger-label mobile asset. No biography or manga commentary appears on the profile.
